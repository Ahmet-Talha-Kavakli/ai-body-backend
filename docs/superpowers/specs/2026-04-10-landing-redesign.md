# Landing Page Redesign — Specification Document

**Date:** 2026-04-10  
**Project:** FitAI Landing Page Modernization  
**Status:** Design Approved

---

## Executive Summary

Transform the FitAI landing page from static to dynamic premium experience with:
- Dynamic aurora gradient background with animated blobs
- Parallax + scale scroll animations for all sections
- Word-by-word text reveals with letter spacing animation
- Custom wave effects on interactive elements
- GSAP + GPU acceleration for 60fps performance
- Avoid AI-generated clichés (neon glow, rainbow gradients)

---

## 1. Visual Foundation

### Background System

**Aurora Gradient Backdrop:**
- Animated gradient that shifts subtly and continuously
- Color progression: Indigo (#6366f1) → Dark Slate (#1a1a2e) → Deep Blue (#0f3460)
- Soft blur effects on gradient transitions
- SVG animated blobs (organic shapes) floating at different speeds (0.5x, 0.3x, 0.1x parallax)
- Background stays fixed/parallax while content scrolls

**Implementation Details:**
- CSS gradient animation with 30s cycle
- 3-5 SVG blobs with individual animation timelines
- Blur filter: 40-60px, updated dynamically
- No visible neon glow or oversaturated colors
- Maintains brand color (#6366f1) as dominant element

**Result:** Sophisticated, alive atmosphere that supports content hierarchy

### Atmosphere & Mood

- Premium and intentional (not "generated by AI")
- Energetic but calm (fitness + AI balance)
- Modern but timeless (avoid trending clichés)
- Dark mode optimized (#080808 background, light text)

## 2. Section Animations — Parallax + Scale

### Scroll-Triggered Entry Pattern

Each section animates on viewport entry with:

1. **Parallax Movement**
   - Background moves at 0.3x scroll speed
   - Section content moves at 1x (normal)
   - Creates depth perception

2. **Scale Animation**
   - Elements start at 0.95 scale
   - Animate to 1.0 as they enter viewport
   - Duration: 600-800ms with easing

3. **Staggered Children**
   - Cards, images, text animate sequentially
   - 50-80ms delay between children
   - All tied to scroll trigger (no auto-play)

### SVG Divider Reveals

Between sections:
- SVG dividers (gradient, glow, or fade variants)
- Reveal animation: 400-500ms
- Gradient mask animation (opacity gradient from 0 → 1)
- Tied to scroll progress

### Performance Targets

- Consistent 60fps on scroll
- GPU acceleration via `transform` and `opacity` only
- Avoid layout thrashing (no width/height animations)
- GSAP ScrollTrigger for viewport detection

## 3. Typography & Text Animations

### Word-by-Word Reveal Pattern

**Target Elements:**
- Hero h1 ("FitAI — Your AI Personal Trainer")
- Section h2s (Features, How It Works, etc.)
- CTA headings

**Animation Details:**
- Each word fades in + slides down (5px)
- Letter spacing animates: 0.05em → 0em during reveal
- Word timing: 60-80ms per word
- Total duration: varies by word count (2-4 seconds typical)
- Trigger: On viewport entry (ScrollTrigger)

**Color Accents:**
- Primary word (e.g., "AI", "Personal") gets indigo highlight
- Subtle color transition during reveal
- No color flashing (use opacity masks)

### Body Text

- Fade in smoothly (no word-by-word churn)
- 400-600ms duration
- Slight delay after heading reveal (200ms)

### Implementation

New component: `TextReveal.tsx`
- Props: `text`, `variant` (h1/h2/body), `accentWords`
- Uses GSAP timeline internally
- Handles stagger and easing

## 4. Interactive Elements — Custom Wave Animation

### Wave Effect System

**On Hover (Buttons, Cards, CTAs):**
- Wave animation originates from cursor position
- Expands outward radially over 600ms
- Wave color: Indigo with 0.3 opacity
- Easing: cubic-bezier(0.34, 1.56, 0.64, 1) (ease-out-back)

**Wave Properties:**
- Radius growth: 0px → 150px
- Opacity: 0.3 → 0 (fade as it expands)
- Blur: 0px → 20px (slight blur on expansion)

**On Click (if applicable):**
- Secondary wave triggers (smaller, faster)
- Primary wave continues

### Button States

- Default: Indigo background, dark overlay
- Hover: Scale 1.02 + shadow elevation + wave start
- Active/Click: Wave animation completes
- No additional color multiplication (keep it minimal)

### Card Hover

- Scale: 1.0 → 1.03
- Shadow: 0px 10px 30px rgba(99, 102, 241, 0.1)
- Wave effect on interactive cards (optional)

## 5. Color & Accent Strategy

### Primary Palette

| Element | Color | Usage |
|---------|-------|-------|
| Background | #080808 | Base layer |
| Primary | #6366f1 | Brand color, headings, interactive highlights |
| Dark Slate | #1a1a2e | Gradient, depth |
| Deep Blue | #0f3460 | Gradient, accents |
| Text Light | #ededed | Body text |
| Text Dark | #262626 | Borders, subtle elements |

### Accent Animation Rules

- **No neon glow** — avoid multiple colored glows
- **No rainbow gradients** — stick to indigo-slate-blue palette
- **Opacity-based emphasis** — use opacity layers instead of bright colors
- **Subtle blur** — glow effects use blur + opacity, not color brightness

### Hover/Active States

- Glow: `box-shadow: 0 0 20px rgba(99, 102, 241, 0.3)` (max)
- Accent highlights: Use opacity shift, not color change
- Transitions: 300-400ms cubic-bezier(0.34, 1.56, 0.64, 1)

## 6. Technical Architecture

### Stack & Libraries

- **GSAP 3.12+** — Main animation engine (ScrollTrigger plugin)
- **React 19+** — Component framework
- **Tailwind CSS** — Styling (custom animation variables)
- **SVG** — Background blobs and dividers
- **GPU Acceleration** — Transform, scale, opacity only

### New Files to Create

```

  │   └── wave-effect.tsx              # Wave animation on hover
  └── ui/

  │   └── gsap-timeline.ts             # Timeline orchestration

apps/web/styles/
  └── animations.css                   # Custom animation keyframes + variables
```

### Modification Strategy

**Minimal changes to existing components:**
- Wrap sections with `<SectionAnimations>` HOC
- Use `<TextReveal>` for headings
- Add wave effect wrapper to buttons

**No refactoring** — Keep existing layout/structure intact
