## 1. Overview

Phase 6 adds intelligent analytics and AI-powered personalization to the mobile app. Users receive personalized recommendations for meals, workouts, health optimization, and social connections. The system learns from Phase 1-5 data (workouts, nutrition, health metrics, social activity) to generate insights and coaching advice.

**Key differentiator:** Unified user embeddings (pgvector) across all domains, multi-domain coaching AI, and contextual recommendations throughout the app.

## 3. Architecture

### 3.1 Data Flow

```
Phase 1-5 Data Collection
  (workouts, meals, health, social activities)
  ↓
Data Aggregation Layer
  (normalize + prepare for embeddings)
  ↓
Embedding Generation (pgvector)
  (user embeddings from all domains)
  ↓
Recommendation Engine
  (collaborative + content-based filtering)
  ↓
Coaching Insights Generation
  (Claude API: performance, nutrition, recovery, behavioral)
  ↓
UI Layer
  (Home cards + Insights tab + contextual recommendations)
```

### 3.2 User Embeddings Strategy

**Input data for embeddings:**
- Meal history (ingredients, cuisines, macros, timestamps)
- Workout history (exercises, intensity, duration, frequency)
- Health metrics (heart rate, sleep, steps, calories)
- Social activity (friends, challenges, badges, streaks)

**Output:** 768-dimensional user embedding (pgvector)
- Captures user preferences across all domains
- Used for: meal recommendations, workout suggestions, friend discovery, challenge matching
- Updated daily or on significant activity

### 3.3 Offline-First Strategy

- **Local cache:** SQLite stores recommendations, insights, embeddings snapshots
- **Fresh generation:** Background sync on app open, periodic updates (6-12 hours)
- **Stale handling:** Show cached recommendations immediately, fetch fresh in background
- **Embedding fallback:** If network unavailable, use last known embedding

## 5. Data Models

```typescript
// User Embedding
interface UserEmbedding {
  userId: string
  embedding: number[] // 768 dimensions
  mealPreferences: { cuisines: string[]; ingredients: string[]; avgMacros: MacroRatios }
  workoutPreferences: { favoriteExercises: string[]; avgIntensity: number; frequency: string }
  healthPatterns: { avgSleep: number; avgSteps: number; heartRateRange: [number, number] }
  socialPatterns: { friendCount: number; challengeParticipation: number; badgeEarningRate: number }
  lastUpdated: string
}

// Recommendation
interface Recommendation {
  id: string
  userId: string
  type: 'meal' | 'workout' | 'health' | 'friend' | 'challenge' | 'coaching'
  title: string
  description: string
  confidence: number // 0-100
  reasoning: string
  actionUrl?: string
  createdAt: string
  expiresAt: string
}

// Coaching Insight
interface CoachingInsight {
  id: string
  userId: string
  domain: 'performance' | 'nutrition' | 'recovery' | 'behavioral'
  title: string
  insight: string // Generated by Claude API
  data: Record<string, any> // Context data
  actionable: boolean
  suggestedAction?: string
  createdAt: string
}

// Analytics Summary
interface AnalyticsSummary {
  userId: string
  period: 'daily' | 'weekly' | 'monthly'
  workoutStats: {
    totalWorkouts: number
    totalDuration: number
    avgIntensity: number
    favoriteExercise: string
    progressTrend: 'up' | 'flat' | 'down'
  }
  nutritionStats: {
    avgCalories: number
    avgProtein: number
    mealsLogged: number
    consistencyScore: number
    favoriteMeals: string[]
  }
  healthStats: {
    avgSleep: number
    avgSteps: number
    avgHeartRate: number
    sleepQuality: number
  }
  socialStats: {
    friends: number
    challengesCompleted: number
    badgesEarned: number
    totalPoints: number
  }
  goals: {
    calorieGoal: number; calorieActual: number
    proteinGoal: number; proteinActual: number
    workoutGoal: number; workoutActual: number
    stepGoal: number; stepActual: number
  }
}

// Insight Card (for Home display)
interface InsightCard {
  id: string
  type: 'recommendation' | 'coaching' | 'achievement' | 'alert'
  title: string
  subtitle?: string
  action: string // "Try this meal", "Start this workout", etc.
  icon: string
  priority: 'high' | 'medium' | 'low'
  expiresAt: string
}
```

## 12. Risks & Mitigations

| Risk | Mitigation |
|------|-----------|
| Embedding generation slow | Cache embeddings, generate in background batches |
| Claude API latency | Cache coaching insights, generate overnight |
| Large recommendation data | Paginate, filter by expiry, local SQLite cache |
| Privacy concerns | Only aggregate user's own data, no cross-user analytics |
| Stale cached recommendations | 6-12 hour TTL, user can refresh manually |
